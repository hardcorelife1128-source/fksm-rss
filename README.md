# 환경신문 비공식 RSS

구독 주소: https://hardcorelife1128-source.github.io/fksm-rss/feed.xml

환경신문(https://fksm.co.kr/) 홈페이지에 노출된 기사 제목과 원문 링크를 RSS 2.0으로 제공합니다. 환경신문이 운영하는 공식 피드가 아닙니다.

- 매시간 17분에 갱신하도록 예약되어 있습니다. GitHub 실행 대기 상황에 따라 지연될 수 있습니다.
- 홈페이지에 노출된 기사만 수집하며, 누적 최대 200개를 유지합니다. 전체 기사 목록을 보장하지 않습니다.
- 본문과 사진을 복제하지 않습니다. 기사 발행일을 확인하지 않은 경우 pubDate를 넣지 않습니다.
- 통신 오류는 최대 3회 재시도합니다. 수집/검증 실패 시 기존 공개 피드를 유지합니다.
- 이미지 설명을 기사 제목으로 오인하지 않도록 검증합니다.

## 수동 갱신과 오류 확인

저장소의 Actions → Update environment news RSS → Run workflow에서 수동 실행할 수 있습니다. 실패한 실행을 열면 단계별 원인을 확인할 수 있습니다.

사이트 구조가 바뀌면 generate_feed.py 수정이 필요할 수 있습니다. GitHub의 요금·이용 정책 및 예약 실행 정책이 적용됩니다.
